# Zaynab Noor E-Commerce & Admin Web App

## Files Included:
1. `index.html` - The complete single-file storefront, product showcase, shopping cart, custom size chart builder, and password-protected admin dashboard.
2. `server.js` - Optional Node.js Express server script to host the store locally on your Windows laptop.

## How to Run:
- **Option 1 (Instant):** Simply double-click `index.html` to open it directly in any web browser (Chrome, Edge, Firefox).
- **Option 2 (Local Server):** Run `npm init -y`, `npm install express`, and `node server.js`.
